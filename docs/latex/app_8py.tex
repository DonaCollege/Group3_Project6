\doxysubsection{Detailed Description}
Streamlit frontend for Financial Analytics API. 

Provides user interface for\+:
\begin{DoxyItemize}
\item Browsing company data
\item Running analytics
\item Performing risk calculations
\item Monitoring API health
\end{DoxyItemize}

Communicates with Fast\+API backend via REST APIs.
